About this document

ภาพรวม

ขั้นตอนที่ผู้เข้าชมเดินผ่านหน้าเว็บ (F0 ถึง F4) ขั้นตอนที่พนักงานร้านใช้จัดการหลังบ้าน (S1 ถึง S6) และโครงสร้างฐานข้อมูล (D1 ถึง D4) ไล่จากระบบที่พัฒนาอยู่ ร่างวันที่ 15 ตุลาคม 2569

ระบบหลังบ้านและฟอร์มติดต่อแบบบันทึกข้อความยังอยู่ระหว่างทดสอบ ยังไม่เปิดใช้บนเว็บจริง และยังไม่ส่งอีเมลแจ้งร้าน ตัวเลขเวลาและจำนวนครั้งเป็นค่าที่ตั้งในระบบตอนนี้ ปรับได้

สัญลักษณ์ใน flow

ขั้นตอนของผู้เข้าชม ขั้นตอนของแอดมิน จุดตัดสินใจ จุดเริ่มและจุดจบ ทางที่ไม่ผ่าน

ป้ายในตารางฐานข้อมูล

PK คือรหัสประจำแถว FK คือคอลัมน์ที่อ้างถึงตารางอื่น ห้ามซ้ำคือค่าต้องไม่ซ้ำกันทั้งตาราง ว่างได้คือไม่ต้องกรอกก็ได้ คอลัมน์ที่ลงท้ายด้วย hash เก็บค่าที่แปลงแล้วย้อนกลับไม่ได้ ไม่มีรหัสผ่านหรือ IP จริงในฐานข้อมูล
