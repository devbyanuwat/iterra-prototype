Flow การใช้งาน
เว็บไซต์ KOHLER Kitchens Thailand

ขั้นตอนที่ผู้เข้าชมเดินผ่านหน้าเว็บ (F0 ถึง F4) และที่พนักงานร้านใช้จัดการหลังบ้าน (S1 ถึง S6) ไล่จากระบบที่พัฒนาอยู่ ร่างวันที่ 15 ตุลาคม 2569

ระบบหลังบ้านและฟอร์มติดต่อแบบบันทึกข้อความยังอยู่ระหว่างทดสอบ ยังไม่เปิดใช้บนเว็บจริง และยังไม่ส่งอีเมลแจ้งร้าน

ผู้เข้าชม

  • F0ประกาศตอนเข้าเว็บ
  • F1ดูสินค้าแล้วสอบถาม
  • F2ค้นหา
  • F3แคตตาล็อก
  • F4ติดต่อร้าน

แอดมินหลังบ้าน

  • S1เข้าสู่ระบบ
  • S2เพิ่มหรือแก้เนื้อหา
  • S3เปลี่ยนแคตตาล็อก
  • S4ตอบข้อความลูกค้า
  • S5แก้ประกาศตอนเข้าเว็บ
  • S6หมวดหมู่ แบรนด์ วัสดุ
ขั้นตอนของผู้เข้าชม ขั้นตอนของแอดมิน จุดตัดสินใจ จุดเริ่มและจุดจบ ทางที่ไม่ผ่าน

F0 · Visitor

ประกาศตอนเข้าเว็บ

ไม่เด้งในหลังบ้าน และไม่เด้งทับแผงค้นหา ข้อความแสดงตามภาษาที่ผู้ชมเลือก ร้านแก้ประกาศได้เองที่ S5

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

F1 · Visitor

ดูสินค้าแล้วสอบถาม

เข้าเว็บ ดูไอเดีย เทียบสินค้า แล้วตัดสินใจติดต่อ

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

F2 · Visitor

ค้นหา

ค้นในเบราว์เซอร์ ผลขึ้นทันที ระบบนับคำค้นเป็นยอดรายวันแบบไม่ระบุตัวตน และไม่เก็บคำที่ดูเหมือนเบอร์โทรหรืออีเมล

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

F3 · Visitor

แคตตาล็อก

เก็บข้อมูลไปคุยที่บ้าน ถ้าร้านเปลี่ยนไฟล์ใหม่ หน้าเว็บเปิด PDF โดยตรงแทนภาพรายหน้าของไฟล์เก่า

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

F4 · Visitor

ติดต่อร้าน

ช่องทางอื่นคือปุ่ม LINE ที่อยู่ทุกหน้า ตอนนี้ยังไม่ส่งอีเมลแจ้งร้าน ข้อความเข้ากล่องในหลังบ้าน (S4)

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S1 · Admin

เข้าสู่ระบบ

พนักงานแต่ละคนมีบัญชีของตัวเอง เมื่อพนักงานลาออก ทีมดูแลระบบปิดบัญชีได้ทันทีและตัดการเข้าใช้ที่ค้างอยู่

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S2 · Admin

เพิ่มหรือแก้เนื้อหา

ใช้กับสินค้า บทความ และผลงาน ทุกการบันทึก เผยแพร่ และลบ เก็บประวัติว่าใครทำ เมื่อไร

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S3 · Admin

เปลี่ยนแคตตาล็อก

ตรวจจากเนื้อไฟล์ ไม่ใช่นามสกุล และตั้งชื่อไฟล์ใหม่ทุกครั้ง

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S4 · Admin

ตอบข้อความลูกค้า

ยังไม่มีอีเมลแจ้งเตือน ร้านต้องกำหนดคนเข้ามาเช็กกล่องข้อความทุกวัน

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S5 · Admin

แก้ประกาศตอนเข้าเว็บ

ต้องมีหัวข้อและเนื้อหาภาษาไทย ถ้าไม่กรอกภาษาอังกฤษ ระบบใช้ภาษาไทยแทน รูปต้องเป็นรูปที่อัปโหลดในระบบ

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน

S6 · Admin

หมวดหมู่ แบรนด์ วัสดุ

ลบได้เฉพาะรายการที่ยังไม่มีสินค้าใช้ ปุ่มลบปิดไว้ให้เห็นก่อน และต้องกดยืนยันก่อนลบ

เลื่อนแผนภาพไปทางขวาเพื่อดูทางที่ไม่ผ่าน
