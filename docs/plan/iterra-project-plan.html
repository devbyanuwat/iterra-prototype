04 งานที่ต้องทำ

งานพัฒนาใน 2 สัปดาห์

มาจากข้อที่ยังไม่ทำและข้อที่รอเนื้อหาจริงในเอกสาร requirement

งานรายละเอียดเสร็จภายใน
แบบฟอร์มติดต่อข้อความจากหน้าติดต่อส่งถึงอีเมลของร้าน พร้อมข้อความยืนยันให้ผู้ส่ง16 ต.ค.
โดเมนและอีเมลชี้โดเมนของร้านมาที่เว็บ เปิดบัญชีอีเมลของร้าน16 ต.ค.
ข้อมูลติดต่อและ LINEที่อยู่ โทรศัพท์ อีเมล เวลาทำการ และ LINE ID จริง20 ต.ค.
ผลงานอ้างอิงใส่โครงการจริง รูปโครงการละหลายรูป และสินค้าที่ใช้21 ต.ค.
บทความใส่บทความจริง หรือคงบทความตัวอย่างตามที่ลูกค้ายืนยัน21 ต.ค.
ประกาศและนโยบายข้อความประกาศตอนเข้าเว็บ และนโยบายความเป็นส่วนตัวฉบับจริง22 ต.ค.
แก้ข้อความแก้ตามผลอ่านทวนของลูกค้า ทั้งไทยและอังกฤษ22 ต.ค.

ไม่อยู่ในแผนนี้: หน้ารายละเอียดรายโครงการ และการเปิดห้องจำลองให้คนทั่วไปใช้ ทำเป็นงานแยกได้ภายหลัง

05 รอจากลูกค้า

สิ่งที่ต้องได้ และวันที่ต้องได้

ถ้าได้ช้ากว่าวันที่ระบุ งานข้อนั้นจะเลื่อนออกไปเท่ากับจำนวนวันที่ช้า

รายการรายละเอียดภายใน
ยืนยัน requirementอ่านและยืนยันเอกสารสรุป requirement13 ต.ค.
โดเมนชื่อโดเมนที่จะใช้ และผู้มีสิทธิ์ตั้งค่า13 ต.ค.
อีเมลปลายทางอีเมลที่รับข้อความจากแบบฟอร์ม และจำนวนบัญชีอีเมลที่ต้องการ14 ต.ค.
ข้อมูลติดต่อที่อยู่ โทรศัพท์ เวลาทำการ LINE ID14 ต.ค.
ผลงานอ้างอิงชื่อ ที่ตั้ง ประเภท ปี รูป และสินค้าที่ใช้ ของแต่ละโครงการ16 ต.ค.
บทความและประกาศเนื้อหาบทความ ข้อความและรูปของประกาศ หรือแจ้งว่าไม่ใช้16 ต.ค.
นโยบายความเป็นส่วนตัวฉบับที่ผ่านการตรวจทางกฎหมาย16 ต.ค.
อ่านทวนข้อความรายการแก้ไขข้อความทุกหน้า รวมตัวเลขสรุปในหน้าแรก19 ต.ค.
ผลทดลองใช้รายการแก้ไขจากการทดลองใช้ในสัปดาห์ที่ 44 พ.ย.
