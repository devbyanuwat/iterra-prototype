05 ความเสี่ยง

จุดที่ต้องระวัง

  • จำนวนคน ยังไม่รู้ ถ้าคนเดียวควบ Backend กับ Frontend หลังบ้าน งาน 19 ถึง 23 ต.ค. จะเลย ต้องตัดสินภายใน 16 ต.ค.
  • เครื่องทดสอบ ต้องพร้อม 21 ต.ค. ไม่งั้น deploy รอบ 1 และวันที่ผู้ดูแลระบบเริ่มเพิ่มสินค้าเลื่อนตาม
  • แคตตาล็อก การสร้างภาพแต่ละหน้าจาก PDF ด้วย scripts/build-media.sh ยังไม่ได้ตรวจว่ารันบน server ได้ ถ้าไม่ได้ ให้เปิด PDF ตรงไปก่อน
  • อัปโหลดรูป ถ้าช้ากว่า 21 ต.ค. เลื่อนไป 26 ต.ค. ผู้ดูแลระบบใส่ข้อความสินค้าได้ก่อน
  • Vercel preview ของแต่ละ PR จะใช้ไม่ได้เมื่อหน้าเว็บต้องต่อ DB ทีมตรวจงานบนเครื่องทดสอบแทน
  • เนื้อหาจากลูกค้า มาช้าได้ทุกข้อ ดูทางสำรองในหัวข้อ 04

06 สมมติฐาน

ที่ยังไม่ได้ยืนยัน

  • ที่ตั้ง DB ตอนพัฒนาใช้ PostgreSQL 16 ในเครื่อง ตอนใช้งานจริงลง Node กับ PostgreSQL บน VPS ของทีมเครื่องเดียวกัน
  • ที่เก็บไฟล์ รูปและ PDF เก็บบนดิสก์ของเครื่อง สำรองพร้อม DB
  • หน้าเสริม 3 หน้า เนื้อหาเขียนในโค้ด ไม่มีหน้าแก้ในหลังบ้าน
