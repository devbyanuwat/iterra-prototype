บันทึกการอัปเดต
เว็บไซต์

สรุปสิ่งที่เพิ่มและปรับปรุงในแต่ละเวอร์ชัน เวอร์ชันล่าสุดอยู่ด้านบน

Version

v0.4

เพิ่มใหม่

  • ปุ่มลอยติดต่อและปุ่มกลับขึ้นด้านบน
  • ช่องค้นหาทั้งเว็บ
  • กล่องประกาศเมื่อเปิดเว็บ
  • หน้าผลงานอ้างอิง และเมนูไปหน้านี้
  • แถบขอความยินยอมคุกกี้ พร้อมหน้าตั้งค่า
  • หน้านโยบายความเป็นส่วนตัว (ข้อความตัวอย่าง รอข้อความจริงจากลูกค้า)
  • หน้าไม่พบหน้า (404) พร้อมลิงก์ไปหน้าแรก สินค้า และค้นหา

ปรับปรุง

  • ปุ่ม LINE มีไอคอนแชตให้เห็นชัดขึ้น
  • ปุ่มกลับขึ้นด้านบนแสดงเร็วขึ้น หลังเลื่อนลงเล็กน้อย
  • การ์ดผลงานเลื่อนเมาส์ผ่านแล้วสลับรูปให้ดู พร้อมแสดงรายละเอียดงาน

Version

v0.3

เพิ่มใหม่

  • ระบบนับสถิติผู้เข้าชม เริ่มทำงานเมื่อผู้เข้าชมยินยอมเท่านั้น

Version

v0.2

ปรับปรุง

  • แยกตู้ วัสดุ และสี ให้เลือกได้ชัดขึ้น

Version

v0.1

เพิ่มใหม่

  • หน้าแรกปรับเป็นเว็บครัวโดยเฉพาะ พร้อมวิดีโอเปิดหน้า
  • ดูแคตตาล็อกบนเว็บได้ทันที ไม่ต้องดาวน์โหลด
  • หน้าสินค้า 10 รายการ พร้อมตัวกรองหมวดหมู่
  • หน้าตัวอย่างวัสดุและผิวงาน
