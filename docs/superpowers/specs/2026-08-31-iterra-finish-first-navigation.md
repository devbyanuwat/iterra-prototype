# ITERRA — นำทางด้วยผิวเคลือบ (Finish-first)

Addendum ต่อจาก `2026-08-31-iterra-ad1-showroom-design.md` · branch `prototype-uxui`

## 1. ทำไมต้องรื้อ

AD-1 build เสร็จ ผ่าน AC ครบ 9 ข้อ Lighthouse 92 — แต่ลูกค้าดูแล้วบอกว่า **ยังไม่ยูนิค** ซึ่งถูก

สาเหตุอยู่ที่ spec เดิม §5: ประกาศกิมมิกไว้ว่า *"สินค้าคือวัตถุในห้องมืด ผิวเคลือบคือแสงในห้อง"*
แล้วรายการ motion ที่เขียนต่อกลับเป็นเอฟเฟกต์ทั่วไป (pin, scrub, parallax, cursor dot)
ไม่มีข้อไหนบังคับกิมมิกนั้นเลย ทีมสร้างตามที่เขียน ผลคือ พื้นดำ + สินค้า + สวอตช์ =
เว็บดำหรูที่ทำได้ดีแต่จำไม่ได้

บทเรียน: **กิมมิกที่ไม่ได้เขียนเป็นข้อบังคับใน spec จะไม่เกิดขึ้น**

## 2. กิมมิกใหม่ — และคราวนี้มันคือโครงสร้าง ไม่ใช่เอฟเฟกต์

> **เว็บนี้นำทางด้วยผิวเคลือบ ไม่ใช่หมวดสินค้า**

ไม่มีเว็บสุขภัณฑ์เจ้าไหนทำ ทุกเจ้าเรียง ครัว/ห้องน้ำ/โถ/อ่าง เหมือนกันหมด รวมถึง Kohler เอง

มันยูนิคเพราะ **มันตรงกับข้อมูลที่เรามีจริง** — ผิวเคลือบคือแกนที่รวยที่สุดในแคตตาล็อกนี้
(11 เฉด กระจาย 4–74 ตัว) และเป็นสิ่งที่คนซื้อของแต่งบ้านตัดสินใจจริง: เลือกโทนก่อน แล้วค่อยหาว่า
มีอะไรให้ในโทนนั้นบ้าง ไม่มีใครเดินเข้าโชว์รูมแล้วพูดว่า "ขอดูหมวดก๊อกครับ"

กิมมิกนี้ยังกลืนฟีเจอร์เดิมได้หมด: สวอตช์ที่ทำไปแล้วไม่ได้ถูกทิ้ง มันเลื่อนขั้นจาก
ปุ่มข้างสินค้า → กลายเป็นตัวนำทางหลักของทั้งเว็บ

## 4. โครงใหม่

### 4.1 หน้าแรก = กำแพงผิวเคลือบ

เต็มจอ 11 แผง ไม่มี hero heading แบบเดิม ไม่มี scroll ก่อนเห็นของ

- แต่ละแผง = รูป swatch ขยายเป็น "สนามวัสดุ" เต็มพื้นที่ ไม่ใช่วงกลมเล็ก ๆ
- ทับด้วย micro-caps: ชื่อเฉด + จำนวนสินค้า
- hover/focus = แผงขยาย แผงอื่นบีบ (flex ratio) — ไม่มี fade ไม่มี modal
- คีย์บอร์ด: ลูกศรเดินระหว่างแผง Enter เข้า
- มือถือ: เรียงแนวตั้ง แผงสูง 1/3 จอ scroll ผ่าน

**ข้อบังคับ:** ห้ามมี category nav บนหน้านี้ ห้ามมีปุ่ม "ดูสินค้าทั้งหมด" เด่นกว่ากำแพง

### 4.2 `/finish/[code]` = แคตตาล็อกของเฉดนั้น

- `--accent` = accent ของเฉดนั้น ตลอดทั้งหน้า
- แสดงเฉพาะสินค้าที่มีเฉดนั้น **และเรนเดอร์ทุกตัวในเฉดนั้น** — นี่คือหัวใจ
  ผู้ใช้เห็นห้องน้ำทั้งห้องในโทนเดียวกัน ซึ่งเป็นสิ่งที่เว็บหมวดหมู่ให้ไม่ได้
- ครัว/ห้องน้ำ ลดชั้นเป็นฟิลเตอร์รองในหน้านี้ ไม่ใช่ nav หลัก
- สลับไปเฉดอื่นได้จากแถบเฉดที่ติดอยู่ขอบจอ — เปลี่ยนแล้วสินค้าทั้งกริด crossfade พร้อมกัน

### 4.3 เลขรุ่นเป็นเลย์เอาต์

ยืมท่าจาก nickho-motorsports โดยตรง: เลขรุ่น (`77959T-4A`) เซ็ตใหญ่ 300–420px
`#FFFFFF` 6% วางหลังสินค้า **ตัดขอบเฟรม** ไม่ใช่จัดกลาง

ใช้ที่: หน้า `/finish/[code]` ต่อการ์ด, และหน้า detail
ห้ามใช้: หน้าแรก (กำแพงผิวต้องไม่มีอะไรแย่ง)

### 4.4 ที่เก็บไว้เหมือนเดิม

`/products` ยังอยู่เป็นทางเข้าแบบเดิมสำหรับคนที่รู้ว่าจะหาอะไร แต่ **ไม่ใช่หน้าแรก
และไม่เด่นกว่ากำแพงเฉด**. `/products/[slug]`, `/about`, `/articles`, `/contact` โครงเดิม
ปรับให้เข้ากับ IA ใหม่. Preloader, SpecDrawing, ProductStage, FinishSwatches ใช้ต่อทั้งหมด

## 5. Acceptance criteria

1. หน้าแรกคือกำแพง 11 เฉด ไม่มี hero heading เดิม ไม่มี category nav
2. เลือกเฉด → `/finish/[code]` แสดงเฉพาะสินค้าที่มีเฉดนั้น **และทุกใบเป็นรูปเฉดนั้นจริง**
   ตรวจ `img src` ไม่ใช่ดูสี
3. จำนวนต่อเฉดตรงกับตาราง §3 เป๊ะทั้ง 11 ค่า
4. `--accent` ของ `/finish/[code]` = accent ของเฉดนั้น
5. สลับเฉดจากแถบขอบจอ กริดเปลี่ยนโดยไม่ต้องโหลดหน้าใหม่
6. เลขรุ่นยักษ์ตัดขอบเฟรมจริง (bounding box ล้นออกนอก container) ไม่ใช่แค่ตัวใหญ่จัดกลาง
7. คีย์บอร์ดเดินกำแพงได้ด้วยลูกศร + Enter · focus ที่มองเห็นบนทุกแผง รวมแผงขาวและแผงดำ
8. 390px: กำแพงเรียงตั้ง ไม่มี horizontal overflow
9. AC เดิมทั้ง 9 ข้อของ AD-1 ยังผ่าน — โดยเฉพาะ reduced-motion และ Lighthouse >= 85
