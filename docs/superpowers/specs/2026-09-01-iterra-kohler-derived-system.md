# ITERRA — ระบบสี/ตัวอักษร/ความหนาแน่น ที่ถอดจาก kohler.co.th

Addendum ต่อจาก `2026-08-31-iterra-finish-first-navigation.md` · branch `prototype-uxui`

## 1. ทำไมต้องรื้ออีกรอบ

ลูกค้าดูของจริงแล้วบอก 3 อย่าง: ตัวอักษรเล็กและบางอ่านยาก · พื้นมืดยิ่งทำให้แย่ ·
เนื้อหาน้อยจนไม่มีน้ำหนัก และของเดิมก่อน AD-1 ยังน่าสนใจกว่า

ทั้งสามข้อถูก และสาเหตุเดียวกัน: ตอนวิเคราะห์ 6 ไซต์จาก GSAP showcase
**screenshot ทุกใบติดหน้า preloader** ผมจึงถอด "DNA" มาจากหน้าโหลด ไม่ใช่หน้าที่มีเนื้อหา
สิ่งที่ได้มา — micro-caps 10px tracking 0.22em, น้ำหนัก 200–300, พื้นเกือบดำ, หนึ่งจอจบ —
คือภาษาของ splash screen ทั้งหมด เอามาใช้กับเว็บที่ต้องขายของ 182 ชิ้นจึงกลวง

รอบนี้วัดจาก **kohler.co.th** ซึ่งเป็นเว็บของแบรนด์ที่งานนี้เป็นดีลเลอร์ให้ ทั้งหน้าแรกและ
หน้าสินค้า เลื่อนจนสุดหน้าแล้ววัดทุก text node

## 3. ระบบใหม่

### 3.1 สี

| token | ค่า | ใช้ที่ |
|---|---|---|
| `base` | `#E5E5E5` | พื้นหน้า |
| `surface` | `#FFFFFF` | การ์ด แผงสเปก |
| `ink` | `#232323` | ตัวอักษรหลัก |
| `dim` | `#5D5D5D` | ตัวอักษรรอง |

`dim` วัดจาก Kohler ได้ `#666666` ซึ่งถูก **แต่ของเขาวางตัวรองบนการ์ดขาวเป็นหลัก**
`#666` บน `#FFFFFF` = 5.74:1 สบาย ๆ ส่วนของเราวางบนพื้น `#E5E5E5` = 4.51:1
ผ่าน AC ข้อ 3 แค่ 0.01 และวัดจริงในเบราว์เซอร์ได้ 4.49 ตอน `Reveal` ยัง tween ค้าง
**ลอกค่าสีมาโดยไม่คิดว่าพื้นหลังต่างกัน คือความผิดพลาดแบบเดียวกับที่ทำให้ต้องรื้อรอบนี้**
จึงเข้มขึ้นเป็น `#5D5D5D` = 5.22:1
| `line` | `rgba(0,0,0,0.10)` | เส้นคั่น |
| `accent` | ตัวแปรจาก finish (เหมือนเดิม) | เส้น kicker · ปุ่ม · index |

รูปสินค้าถ่ายมาบนพื้นขาวอยู่แล้ว การวางบนพื้นสว่างจึงเป็นธรรมชาติกว่า
**งานลอกพื้นขาวไม่เสียเปล่า** — PNG โปร่งบนการ์ดขาวยังคมกว่ารูปพื้นขาวทึบบนการ์ดขาว
เพราะไม่มีขอบกล่องให้เห็น

`--focus-ring` เปลี่ยนจาก cream เป็น `#232323` (contrast บน `#E5E5E5` = 13.2:1)
เหตุผลเดิมยังอยู่: ค่าที่ต้องรับประกัน contrast ห้ามขับด้วยข้อมูลสินค้า

### 3.2 ตัวอักษร

| บทบาท | ขนาด/น้ำหนัก | หมายเหตุ |
|---|---|---|
| เนื้อหา | **16px / 400** lh 1.6 | ขั้นต่ำ ห้ามต่ำกว่านี้ |
| เนื้อหารอง | 15px / 400 · สี `dim` | |
| หัวการ์ด | 24px / 400 lh 1.25 | |
| หัวข้อ section | 32px / 400 | |
| h1 หน้าสินค้า | 30px / 600 | Kohler ใช้ 22/700 — เราใหญ่กว่าได้เพราะหน้าโล่งกว่า |
| ป้ายกำกับ | **15px / 500 uppercase tracking 0.12em** | แทน micro-caps 10px/.22em เดิม |

ตารางนี้เคยเขียนป้ายกำกับไว้ 13px ซึ่ง**ขัดกับ AC ข้อ 1 ของ spec เดียวกัน**
ที่บอกว่าไม่มีข้อความที่ต้องอ่านตัวไหนเล็กกว่า 15px — และป้ายกำกับก็คือข้อความที่ต้องอ่าน
AC เป็นข้อที่ถูกวัดจริง จึงชนะ ตัวพิมพ์ใหญ่ + tracking 0.12em ทำให้มันยังอ่านเป็นป้ายได้ที่ 15px
| เลขรุ่นยักษ์ | คงเดิม | ละตินล้วน ยกเว้นจากกฎไทย |

**ห้ามใช้น้ำหนัก 200 และ 300 กับข้อความที่ต้องอ่าน** — เหลือไว้เฉพาะตัวตกแต่งขนาดใหญ่
กฎ line-height ไทย 1.08 บน heading ยังอยู่

### 3.3 ความหนาแน่นของหน้าแรก

เป้า **≥ 3.5 จอ** ลำดับ:

1. กำแพงผิวเคลือบ 11 เฉด (100svh) — ยังเป็นตัวนำทางหลัก
2. ชิ้นเด่น — กริดสินค้า 6–8 ชิ้นจากเฉดที่มีของเยอะสุด
3. เลือกตามห้อง — ครัว / ห้องน้ำ พร้อมจำนวนจริง
4. เรื่องของเรา + ตัวเลข (ดึงกลับจากของเดิมที่ถูกลบไป)
5. บทความ 3 ชิ้น
6. ติดต่อ/โชว์รูม

ข้อ 4 และ 5 มีอยู่แล้วใน `components/home/HomeContent.tsx` เดิม (git history)
ไม่ต้องเขียนใหม่ ดึงกลับมาแล้วเปลี่ยน token

## 4. Acceptance criteria

1. ไม่มีข้อความที่ต้องอ่านตัวไหนเล็กกว่า 15px หรือน้ำหนักต่ำกว่า 400 —
   ตรวจด้วยการวัด computed style ทุก text node ไม่ใช่ grep คลาส
2. หน้าแรก ≥ 3.5 จอ · ≥ 30 รูป · ≥ 6 heading
3. contrast ตัวอักษรหลักบนพื้น ≥ 7:1 · ตัวอักษรรอง ≥ 4.5:1
4. focus ring มองเห็นบนทั้งพื้น `base`, การ์ด `surface` และทุกแผงของกำแพง
5. AC เดิมของ finish-first ยังผ่านครบ (กำแพง 11 เฉด · จำนวนตรง §3 · คีย์บอร์ด · 390px ไม่ล้น)
6. AC เดิมของ AD-1 ที่ยังใช้ได้: build เขียว · reduced-motion · ไม่มีตะกร้า · Lighthouse ≥ 85
